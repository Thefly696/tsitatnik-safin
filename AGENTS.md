# Инструкции AI-агенту: серверный пайплайн «Цитатник Сафина»

## Область ответственности
Поддерживай Python-пайплайн в `/scripts/`, JSON-контракт в `/docs/widget_data.json`, GitHub Actions и README. Не изменяй Android-код без прямого запроса. Не публикуй секреты, токены или персональные данные.

## Тематические теги цитат
Каждая цитата с `is_meaningful: true` должна получать строго 1–2 тематических тега. Для отклонённого поста (`is_meaningful: false`) возвращай пустой массив `tags: []`.

Разрешён только следующий фиксированный словарь. Перед сопоставлением Python удаляет ведущие решётки и пробелы, сравнивает без учёта регистра и сохраняет каноническое написание из словаря:
`["Границы", "Отношения", "Семья", "Тревога", "Самооценка", "Эмоции", "Ответственность", "Выбор", "Зависимость", "Осознанность"]`

Gemini должен возвращать поле `tags` в каждом объекте ответа. Python обязан нормализовать теги (убрать ведущие # и пробелы, сопоставить без учёта регистра), вернуть каноническое написание из белого списка, сохранить порядок, удалить дубли и оставить не более двух тегов. Если содержательная цитата не получила ни одного допустимого тега, обработка должна завершиться ошибкой без перезаписи JSON. Неизвестные теги и значения нестрокового типа не сохраняются. Для незначимых постов принудительно записывается пустой массив.

## JSON-контракт
В объекте цитаты сохраняются `post_id`, `published_at`, `generated_at`, `summary`, `source_url`, `tags` (массив строк) и `generated_by` (точный ID модели Gemini). Не переименовывай и не меняй типы существующих полей, `schema_version` и `app_update`. Сортировка и дедупликация по `post_id`, хранение за 30 дней и атомарная запись обязательны.

## Закреплённые цитаты Gemini

По умолчанию `LOCKED_MODELS=gemini-4-hydrogen`; переменная принимает список ID через запятую. Цитата закреплена, если её `generated_by` входит в этот список, а `summary` и `tags` непустые. При `FORCE_REGENERATE=true` и `OVERWRITE_LOCKED=false` закреплённые цитаты нельзя отправлять в Gemini или изменять. Записи без `generated_by`, с пустыми `summary`/ `tags` или от незакреплённых моделей разрешено улучшать. `OVERWRITE_LOCKED=true` снимает защиту.

## Проверки
После любых изменений в `/scripts/` запускай:
```bash
python -m unittest discover -s scripts/tests -v
```
Не коммить изменения, пока тесты не пройдены.
