# Инструкции AI-агенту: серверный пайплайн «Цитатник Сафина»

## Область ответственности
Поддерживай Python-пайплайн в `/scripts/`, JSON-контракт в `/docs/widget_data.json`, GitHub Actions и README. Не изменяй Android-код без прямого запроса. Не публикуй секреты, токены или персональные данные.

## Тематические теги цитат
Каждая цитата с `is_meaningful: true` должна получать строго 1–2 тематических тега. Для отклонённого поста (`is_meaningful: false`) возвращай пустой массив `tags: []`.

Разрешён только следующий фиксированный словарь (регистр и написание значимы):
`["Границы", "Отношения", "Семья", "Тревога", "Самооценка", "Эмоции", "Ответственность", "Выбор", "Зависимость", "Осознанность"]`

Gemini должен возвращать поле `tags` в каждом объекте ответа. Python обязан фильтровать теги по белому списку, сохранять порядок, удалять дубли и оставлять не более двух тегов. Неизвестные теги и значения нестрокового типа не сохраняются. Для незначимых постов принудительно записывается пустой массив.

## JSON-контракт
В объекте цитаты сохраняются `post_id`, `published_at`, `generated_at`, `summary`, `source_url` и новое поле `tags` (массив строк). Не переименовывай и не меняй типы существующих полей, `schema_version` и `app_update`. Сортировка и дедупликация по `post_id`, хранение за 30 дней и атомарная запись обязательны.

## Проверки
После любых изменений в `/scripts/` запускай:
```bash
python -m unittest discover -s scripts/tests -v
```
Не коммить изменения, пока тесты не пройдены.
